verl × Ray — how a single-controller framework drives an RL training cluster

A small set of explainers on verl and how it uses Ray effectively for RL post-training (PPO / GRPO). The throughline: one driver process runs the algorithm, while a fleet of Ray actors — one per GPU — does the model math, bridged by the verl.single_controller dispatch layer.
